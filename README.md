# Samuel Akira Stace — Workaway portfolio

Static portfolio site for Samuel Akira Stace.

## Publish with GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then click **Save**.
4. The site will be available at https://samstace.github.io/workaway-portfolio/

The video gallery uses the public Google Drive folder supplied by Samuel. Image assets are optimized copies of the local portfolio files.
